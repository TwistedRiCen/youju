# M4 运维手册

适用对象：维护有据 YouJu V0.1 M4 公开演示（同源静态 Web + 单实例无状态 Fastify + 受信反向代理）的运维人员。

## 1. 拓扑与健康

| 组件        | 检查                          | 期望                                                                        |
| ----------- | ----------------------------- | --------------------------------------------------------------------------- |
| Fastify API | `GET /health`                 | `200 {status:'ok', releaseId}`；releaseId 与 `/release.json`、`/about` 一致 |
| 静态 Web    | `GET /`、`/privacy`、`/about` | `200`，携带安全头与正确缓存头                                               |
| 发布配对    | `/health` vs `/release.json`  | 两者 releaseId 相同；不一致即视为发布异常并回滚                             |

健康检查只返回状态与发布编号，不暴露环境变量、依赖版本或 Provider 配置。

## 2. 告警

| 信号           | 阈值建议       | 处理                                     |
| -------------- | -------------- | ---------------------------------------- |
| `/health` 失败 | 任意失败       | 检查 API 进程、端口、代理上游配置        |
| 5xx 比率       | 高于平时基线   | 检查 Provider 可达性、超时策略与资源占用 |
| 延迟           | 尾延迟显著上升 | 检查单实例资源与 Provider 目标延迟       |
| 证书到期       | 到期前 14 天   | 更新全链证书并重载代理                   |
| 磁盘/内存      | 资源耗尽       | 无业务数据落盘；优先检查日志与构建残留   |

Provider 故障只影响 AI 增强：无 AI 手工流程必须继续可用。任何 AI 故障不得回退到本地优先边界之外。

## 3. 日志保留与安全

- 应用日志只保留低敏元数据：请求 ID、路由类别、状态类别、耗时、Provider 预设与稳定错误类、粗粒度 IP 分类（ipv4/ipv6）、Origin 与 Fetch Metadata 类别；不得出现原始 IP、完整 User-Agent、请求体、响应体、文件名、事件标题、API Key 或模型内容。
- 日志保留最长 7 天，平台允许时更短；到期自动滚动删除。
- 日志访问控制：仅授权运维人员可读；不得把日志接入第三方分析、追踪或回放服务。

## 4. 证书与 DNS

- 全链证书由代理终止 TLS；私钥只存放在代理侧并限制文件权限。
- DNS 变更前记录当前解析结果；变更后验证解析与证书主机名一致。
- HSTS 首版为 `max-age=31536000`（一年），不含 `includeSubDomains` 与 preload；调整策略前需要新的发布决策。

## 5. 访问控制

- 服务器仅允许运维人员经批准的入口访问；API 不提供管理端点。
- 受信代理出口地址变化时同步更新 `TRUSTED_PROXY_CIDRS`（显式列表，禁止 `true`/`*`/`0.0.0.0/0`/`::/0`），并重启 API。
- 代理必须覆盖客户端伪造的 `X-Forwarded-*` 头并自设 `X-Forwarded-Proto`。

## 6. 部署与回滚

- Web 与 API 按同一发布编号成对发布与回滚（步骤见[公开演示部署指南](public-demo.md)）。
- 每次发布记录：发布编号、静态/API 产物摘要、冒烟结果与回滚点。
- 回滚后重跑冒烟，确认 `/health` 与 `/release.json` 重新配对、本地浏览器数据不受影响。

## 7. 故障手册

| 现象                 | 可能原因                    | 处置                                                           |
| -------------------- | --------------------------- | -------------------------------------------------------------- |
| `/health` 无响应     | API 进程退出/端口占用       | 检查进程与 `PORT`，按第 6 节回滚或重启                         |
| 首页 404/无样式      | 静态目录或 SPA 回退配置错误 | 核对 `${STATIC_ROOT}`、`try_files` 与 `/index.html` 规则       |
| 浏览器 AI 请求被 403 | Origin/代理头不匹配         | 核对代理自设 `X-Forwarded-Proto` 与 `TRUSTED_PROXY_CIDRS`      |
| 长任务 504           | 代理读取超时过短            | `proxy_read_timeout` 必须 ≥ 130s                               |
| 更新不生效           | SW 缓存或发布配对错误       | 核对 `sw.js`/`release.json` 重新校验与发布编号；必要时成对回滚 |
| Provider 全部失败    | Provider 侧故障或条款变更   | 无 AI 手工流程继续可用；AI 状态页保持诚实错误提示              |
